# Dell Inspiron 7590 OpenCore

OpenCore configuration and related resources for the Dell Inspiron 7590.

## Contents

- `EFI/` — OpenCore boot files and configuration
- `IMG/` — Project images

## Hardware Support

- HDMI: Not tested.
- Microphone: Only an external microphone is supported.
- Bluetooth, Wi-Fi, and the dedicated GPU: Fully supported.

Use at your own risk. Hardware configurations may vary.
